A web-based Wordle clone built with Python and Flask. 
This single-file application includes user registration/login, game logic with color-coded hints, and admin reporting, with all data saved to a database. 
To run this project, first ensure you have Python 3 and install the required dependencies.
Save the code and start the server with python app.py
Before playing, you must initialize the database one time by visiting http://127.0.0.1:5000/init-db in your browser. 
After that, you can register an account and log in to play.
